🖥️ Fullscreen Mode Testing

What is Fullscreen Mode?

  • Expands the chat widget to cover the entire viewport (100% width & height)
  • Positioned at coordinates (0, 0) - top-left corner of screen
  • Provides an immersive chat experience on any screen size
  • Can be toggled via the expand/collapse button in the header

✅ Test Checklist

  • Open the chat widget by clicking the toggle button (bottom-left)
  • Look for the expand button (⤢ icon) in the chat header
  • Click the expand button - widget should fill entire screen
  • Widget should cover 100% width and 100% height
  • Widget should be positioned at top-left (0, 0)
  • Press ESC key - widget should collapse back
  • Click the collapse button (⤡ icon) - widget should return to normal size
  • Normal widget dimensions should be restored
  • Widget should return to configured position (bottom-left)
✓ Expected Behavior:
• Fullscreen: 100% width, 100% height, position (0, 0)
• Normal: 350px width, 600px height, bottom-left with 20px offset
• ESC key exits fullscreen mode
• Smooth transition animation

⌨️ Keyboard Shortcuts

  • ESC - Exit fullscreen mode
  • Works from anywhere when widget is in fullscreen

🎨 Custom CSS Support Testing

What is Custom CSS Support?

  • Allows loading external CSS file to customize widget appearance
  • CSS is injected into the Shadow DOM (no conflicts with host page)
  • Supports both absolute and relative paths
  • Can override default widget styles
